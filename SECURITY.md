# Security Policy

## Supported versions
This repository is a standards and documentation package. Updates to guidance, schemas, and benchmarks are published on the main branch and via tagged releases when available. If you are consuming a release, we recommend staying on the latest tagged version.

## Reporting a vulnerability
If you believe you have found a security issue in this repository (including benchmark harness code, tooling, or documentation that could cause unsafe behavior), please report it privately.

1. **Email**: security@socioprophet.org
2. **Subject**: "Security issue in socioprophet-standards-storage"
3. **Include**: a clear description, steps to reproduce, potential impact, and any relevant logs or screenshots.

We aim to acknowledge reports within **3 business days** and will provide a status update within **10 business days**. Please do not open public issues for security reports until we have responded.

## Coordinated disclosure
We follow coordinated disclosure practices. We may request additional details, a proof of concept, or retesting against a fix.
