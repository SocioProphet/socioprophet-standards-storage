# Architecture Decision Records (ADRs)

This directory stores the Architecture Decision Records that document key platform decisions and their rationale.

## Contents
- `ADR-000-template.md` — template for new decisions.
- `ADR-010-storage-portfolio.md` — storage portfolio selection and triggers.
- `ADR-020-graph-store-abstraction.md` — graph store abstraction strategy.
- `ADR-030-knowledge-context-repo-split.md` — repository boundaries for knowledge contexts.

## Contributing
When adding a new ADR:
1. Copy the template.
2. Assign the next available numeric identifier.
3. Summarize the decision and its consequences.
