# Workload Definitions

This directory contains YAML definitions for benchmark workloads. Each workload describes data shape, query patterns, and performance expectations.

## Usage
1. Select the workload YAML files relevant to your system.
2. Load them into the benchmark harness configuration.
3. Record results using the reporting format in `docs/benchmarks/`.

## Contributing
When adding a workload definition:
1. Follow the naming conventions in existing YAML files.
2. Document the intent and expected metrics.
3. Ensure the workload maps to a benchmark category in the catalog.
