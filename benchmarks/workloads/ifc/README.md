# IFC Conformance Workloads

This directory holds fixture scaffolds and certification workload definitions for the Incidence Fabric Contract (IFC).

Initial intent:
- fixture packs for projection downgrade checks,
- contradiction-aware query checks,
- identity merge/split review checks,
- obligation-preserving derivation checks,
- backend-profile certification slices.

Follow-on files in this directory should remain machine-oriented and companion the higher-level certification templates under `docs/benchmarks/`.
