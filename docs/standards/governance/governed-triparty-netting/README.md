# Governed Triparty Netting Fabric

This package contains the publication-grade white paper and companion materials for the governed triparty netting fabric.

## Contents
- `whitepaper.md` - publication-grade long-form paper
- `one-page-summary.md` - concise overview
- `asi-snet-integration-brief.md` - ASI / SingularityNET integration brief
- `worked-example.md` - bounded worked example
- `positioning-note.md` - alignment and posture note
- `schema-companion.md` - schema-oriented companion

## Purpose
These materials codify the governed triparty netting fabric as a standards-facing doctrine and integration package that can sit above current ecosystem rails without subordinating the architecture to any single chain, bridge, registry, or marketplace.

## Notes
This package is intended as a canonical governance and standards artifact. Downstream partner packets, grant kernels, and outreach materials may summarize it but must not redefine its constitutional terms.
