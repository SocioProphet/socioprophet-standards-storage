# Evidence Pack Checklist

## Core records
- Partner profile complete
- Instrument decision worksheet complete
- Capacity assessment complete
- Signed instrument on file
- Approvals on file
- Reporting calendar on file

## Risk and safeguards
- Safeguarding controls checked
- Incident channels documented
- Data governance schedule attached
- PCAT or micro-assessment status recorded
- Conflict or recusal log current
- Current risk flags recorded

## Monitoring and closeout
- Latest progress evidence stored
- Corrective actions tracked
- Advisory recommendations cross-referenced
- Closeout or transition note prepared
- Data deletion or handback complete
- Lessons fed back into ecosystem map
