# Governed CSO Partnership Field Sheet (2026)

## Use sequence
1. Screen the actor and create the partner profile.
2. Decide the correct instrument and document why.
3. Apply capacity scoring and stop-rules.
4. Attach safeguarding and data requirements.
5. Open the evidence pack.
6. Escalate incidents through the incident form.
7. Close with lessons and data disposition.

## Stop-rules
- If safeguarding is below minimum, pause or narrow the engagement.
- If fiduciary controls are below minimum, do not delegate fund management.
- If data controls are below minimum, do not permit sensitive-data handling.
- If civic-space risk is acute, redesign the operating model to reduce exposure.
