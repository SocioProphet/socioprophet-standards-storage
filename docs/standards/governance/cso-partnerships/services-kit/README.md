# Governed CSO Services Engagement Kit

This package derives customer- and delivery-facing operating materials from the canonical governed CSO partnership standard already housed in this repository.

## Purpose
Use this kit when we need to move from normative standard to an actual scoped engagement with a customer, programme team, or implementation partner.

## Contents
- `intake-questionnaire.md` - structured discovery intake
- `scope-and-instrument-fit.md` - scope framing and instrument-choice worksheet
- `governance-cadence.md` - recurring governance and review rhythm
- `evidence-and-reporting-bundle.md` - minimum evidence, reporting, and checkpoint expectations
- `incident-and-escalation-path.md` - practical incident path for service delivery
- `closeout-criteria.md` - closure, handback, and lesson-capture rules

## Relationship to the canonical standard
This kit does not replace the governed CSO partnership framework. It translates that framework into a customer/services operating lane.
