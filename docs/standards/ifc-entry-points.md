# IFC Entry Points

## Purpose
Provide a standards-layer discoverability note for the Incidence Fabric Contract (IFC) surfaces without requiring readers to traverse the entire repository structure.

## Primary IFC standards
- `132-incidence-fabric-contract.md`
- `133-ifc-backend-capability-profiles.md`
- `134-ifc-theoretical-foundations.md`
- `governance/agentplane-ifc-governance.md`
- `ifc-index.md`

Located under `schemas/ifc/` and `schemas/ifc/examples/`.

Key schema families include:
- loss certificate
- query IR
- backend capability profile
- authorization grammar
- merge conflict
- contradiction and competing-claim
- delegation and obligation
- fixture result
