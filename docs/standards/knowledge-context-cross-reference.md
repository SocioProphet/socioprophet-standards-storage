# Knowledge Context Cross-Reference

Semantic ontology implementation and policy-pack work for the Ontogenesis core lives in `SocioProphet/socioprophet-standards-knowledge`.

That includes the canonical semantic core for:

- Prophet CLI ontology
- Atomic Bindings
- Human privacy-aware ontology
- SocioProphet runners, experiments, and reports

This storage repository remains the canonical source for:

- storage contexts
- data contracts
- service interfaces
- benchmarks and workload methodology
- governance posture for the storage and measurement surface

## Repository split

Use `SocioProphet/socioprophet-standards-knowledge` when the work is primarily about ontology structure, semantic validation, SHACL policy packs, JSON-LD contexts, and semantic governance.

Use `SocioProphet/socioprophet-standards-storage` when the work is primarily about storage contracts, interfaces, benchmarking, measurement, and storage-governance standards.
