## Scope

- **Target certification**: FIPS 140-2 Level 2 (path to Level 3 in subsequent cycle)
- **Repositories in scope**: 50+ SocioProphet repositories
- **Timeline**: 9 months (Q2–Q4 2026)
- **Budget**: $155,000 (approved)
- **Team**: 11–17 FTEs
