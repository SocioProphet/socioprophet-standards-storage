# Storage Fabric Benchmark Methodology

This section defines benchmark and reporting methodology for workload-shaped storage-fabric evaluation.

It covers:
- storage benchmark reports
- service benchmark reports
- benchmark history reports
- history-horizon activation rules

Service evidence uses:
- `PASS` when live execution succeeded
- `FAIL` when a configured service was broken or unreachable
- `SKIP` when the service benchmark was not executed and therefore cannot be treated as positive evidence

Executable harnesses, integration matrices, and generated fixtures belong in downstream conformance repositories.
